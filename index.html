OpenVehicle

Fact-check for everyone — facts you can cite, and facts you can check.

OpenVehicle is the canon's reference rails: the standard vehicle （車同軌） that carries verified facts out of the school into the whole world — wikis, posts, classrooms, other AIs. 事實要有得引、有得查。

What it is

Canon Explorer is the reading room inside the school; OpenVehicle is the railway out. Both read the same one canon; neither forks it. Anyone pastes a claim, and the answer comes from canon with labels and sources — or an honest 「未有收錄」, and that gap itself joins the ingest queue. For AIs, the same check is an API/MCP call: DawnSci oracles numbers, OpenVehicle oracles facts.

Every fact citable — ID + URL + truth label + sources Correction history — canon corrects, the correction propagates Fact-check as a public service API / MCP for AIs Honest gaps — 未有收錄 becomes an ingest seed

END GOAL

A reference anyone can actually check, in their language, playful enough to use — the school's public duty at world scale: 見者知，知者行. A Dawn fact, referenced anywhere, resolves back to canon; every citation anywhere is a road back to Dawn, and if canon corrects the fact, the correction travels the same rails.
